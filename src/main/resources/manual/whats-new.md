# What is new
## 23 October 2026
- APIs page shows the real Base URL and API path of every API, explains Tests / Auth / Contract, and Edit address lets you paste one full URL (Studio splits it), set a project-wide base URL and try the API at once.
- A run keeps going when you open another page: a button at the top shows its progress (and an OTP request), a pop-up tells you when it finishes, and Live run shows the last run and earlier runs.
- Group cards show Waiting / Running n of m / Completed.
- Live console and the saved report now look and work like the legacy API Automation console (KPI tiles, progress with time left, execution map, filters, Pause, TV, theme).
- The OTP step is skipped automatically when the login does not ask for an OTP.
- Credentials can be saved on this PC (encrypted) with a Show button, and the Credentials card says when a project signs in by itself.
- Clear old records starts a project fresh.
- Optional AI engine (off by default, local or on another machine): Test ideas page, plain-English failure explanations. Auto-heal repairs after a spec comparison. Export as Karate or Rest Assured code.
- The left menu is grouped in four steps: Get ready, Build tests, Run, Results.
